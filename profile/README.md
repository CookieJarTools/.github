### Installing any of them

Open `Window > Package Manager`, press **+**, choose **Install package from git URL**, and paste
the repository address with `.git` on the end:

```
https://github.com/CookieJarTools/Cookbook.git
```

Or put the line straight into `Packages/manifest.json`:

```json
"com.cookiejartools.cookbook": "https://github.com/CookieJarTools/Cookbook.git"
```
