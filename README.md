# .github

Organisation files for [CookieJarTools](https://github.com/CookieJarTools).

The page people see at the top of the organisation is
[`profile/README.md`](profile/README.md). GitHub only reads it from that exact path, so the
readme in this root is just a note about the repository itself.

Adding a tool to the shelf means three things in `profile/README.md`: a cell in the table with
the tool's hero picture, a line of what it does taken from its own readme, and the Unity version
it needs. The banner at the top is drawn by a script and saved as `profile/banner.png`.
